# GoldLink Market Hub

Create a professional, modern, responsive website called GoldLink AI.

The website connects gold and cryptocurrency markets in one platform.

Design requirements:

- Dark navy background with elegant gold accents.

- Modern financial dashboard.

- Clean typography and simple navigation.

- Responsive layout for desktop, tablet, and mobile.

Main sections:

1. Homepage introducing GoldLink AI.

2. Gold price dashboard.

3. Bitcoin and Ethereum price dashboard.

4. Cryptocurrency-to-gold converter.

5. Gold and cryptocurrency comparison charts.

6. AI assistant section.

7. Simulated exchange demonstration.

Make the website look professional, trustworthy, and easy for beginners to use.

For now, create the visual design and page structure. Do not use fake live prices or claim that APIs are connected.
